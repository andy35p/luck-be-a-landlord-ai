# V0.3.9：牌组数量单变量实验

结论：在固定三轮预算下，增加显式牌组数量没有得到改善证据，保留原 BC 模型为当前参考。没有继续调参或扩大训练。

## 唯一修改与控制

CandidateModel 增加可选 deck_count，默认 false 保持旧检查点兼容。新特征为 deck_mask 有效实例数 / 20，不裁剪、不拟合统计。它在共享评分头输入末尾追加，模型参数从 7489 增至 7553。新列权重从零开始，其余权重与原版相同；初始化评分相同，测试验证全部共享权重逐项一致。计数不包含填充，复制实例会改变数量特征。

配置 `configs/bc_count_v1.json`：同一教师、数据、缩放、初始化种子 36、三轮、534 次更新、batch_size=64、学习率 0.001、打乱种子 42、在线种子 1000–1099。依然使用最终轮检查点，无筛选。未训练对照与教师逐局 CSV 均与上轮完全一致。

## 结果

| 指标 | 原模型 | 数量特征模型 |
|---|---:|---:|
| 开发验证准确率 | 87.52% | 86.98% |
| 开发验证 NLL | 0.2676 | 0.2683 |
| test 符号严格匹配 | 275/385 | 273/385 |
| 教师同分换选 | 86 | 88 |
| 选取/跳过分歧 | 24 | 24 |
| 100 局平均通过租金 | 5.38 | 5.22 |
| 第三期通过率 | 100% | 100% |
| 通关局数 | 8 | 8 |
| 截断局数 | 0 | 0 |

逐种子差值均值 -0.16，5000 次配对 bootstrap 的 95% 区间 [-0.62, 0.29]。10 局改善、75 局不变、15 局下降；区间跨零，不能据此断言数量特征普遍有害，也不能认为它有效。

上轮最差五局中，1004 从通过 4 期改善为 5 期，1011、1015、1044、1061 仍为 4 期。新的下降局包括 1022、1049，从原模型通过 13 期降为 4 期。离线选取/跳过分歧没有减少，因此没有实现本轮期望的纠正效果。

均值汇总丢失数量的表示问题确实存在，但增加一个可学习数量输入不意味着三轮训练就能学会教师的阈值。这次实验只检验固定预算下的这种接入方式；不证明此前所有跳过错误都由数量缺失引起。
