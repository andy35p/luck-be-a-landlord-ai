# V0.4.3：教师标注数据聚合的匹配预算对照

结论：本轮 50% 标注数据混合没有得到稳定改善证据，不替换当前参考模型，也不追加轮数。所有结果限于已消费的开发数据与受限环境。

## 实验控制

遵循 configs/bc_aggregation_v1.json。两臂均从原始 7489 参数架构的相同种子 36 初始化，不使用牌组数量特征，不从旧检查点继续训练。相同 Adam 学习率 0.001、梯度裁剪 1、旧训练集拟合的冻结缩放、534 次更新，每次 64 条多选决策。最终更新检查点用于比较，不按验证结果选择。

- baseline：原始教师轨迹，34176 次有效决策抽样。
- candidate：原始教师轨迹与模型自身状态的教师标注，各 17088 次，共 34176 次。

按来源循环打乱抽样，重复是预算内有意采样。标签来自明确的 teacher_action，监督批次不含执行动作的奖励或下一状态。数据只含此前训练分区的种子；未把在线评估种子混入训练。

这个原始组是新匹配预算基线。它不等同于 V0.3.7 包含唯一动作的三轮训练，不能将这次变化全部归因于聚合数据，必须比较本轮两臂。

## 开发结果

| 指标 | 本轮原始组 | 50% 聚合组 |
|---|---:|---:|
| 验证多选准确率 | 88.07% | 86.98% |
| 验证 NLL | 0.2648 | 0.2617 |
| test 符号严格匹配 | 275/385 | 260/385 |
| test 教师同分换选 | 86 | 94 |
| test 选取/跳过分歧 | 24 | 31 |
| 100 局平均通过租金 | 5.01 | 5.17 |
| 第三期租金通过率 | 100% | 100% |
| 通关局数 | 6 | 11 |
| 截断局数 | 0 | 0 |

在线使用同一组开发种子 1000–1099。平均通过租金差值 +0.16，5000 次配对 bootstrap 的 95% 区间 [-0.25, 0.63]；13 局改善、59 局相同、28 局下降。少数较大改善可抬高平均值，而下降局数仍更多；通关局数也不能单独证明策略更强。未进行多随机初始化验证，区间只反映这组逐局配对差异。

聚合组的选取/跳过分歧从 24 增为 31，没有达到本轮希望纠正的离线行为；教师同分换选同样增多。不能仅凭验证 NLL 小幅下降决定替换策略。教师在当前状态上的启发式标签也不是真实最优动作价值。
