# V0.6.9：固定小子集拟合检查

现有空间模型能完整拟合本次选定的 128 个教师训练决策：准确率从 67.19% 提升到 100%，平均负对数似然从 0.758279 降到 0.006400。这是记忆能力诊断，不是泛化或游戏胜率提升的证据。

## 预先固定的实验

- 仅使用 V063 的 heuristic/train，沿用按种子分组的划分，不读取 validation、test 或模型自身诊断轨迹进行训练。
- 从 V066 最终权重出发，冻结原归一化，模型架构不变。
- 四个互斥组各 32 条：教师选老鼠且牌组有奶酪；教师选奶酪且牌组有老鼠；其余牌组大小 18–19 的符号决策；其余符号决策。协同组优先，伙伴数量统计当前牌组。
- 按 `sha256(v069:seed:step)` 排序抽取，不按模型错误筛选；在预测或拟合前保存 selection.json。组内可能包含同分选项，此处统计精确教师标签一致率。
- 固定 Adam 学习率 0.001、全批次 128、梯度裁剪 1、400 次新增更新、CPU 单线程、种子 69。无提前终止或预算追加。

## 结果

| 更新次数 | 总准确率 | 平均负对数似然 |
|---|---:|---:|
| 0 | 67.19% | 0.758279 |
| 100 | 95.31% | 0.165309 |
| 200 | 100% | 0.040963 |
| 300 | 100% | 0.013586 |
| 400 | 100% | 0.006400 |

| 组别（各 32 条） | 初始准确率 | 最终准确率 |
|---|---:|---:|
| 老鼠、有奶酪 | 43.75% | 100% |
| 奶酪、有老鼠 | 90.63% | 100% |
| 其余牌组 18–19 | 65.63% | 100% |
| 其余符号决策 | 68.75% | 100% |

全部梯度与损失有限；保存重载后 128 条样本的评分逐项完全一致。原 V066 权重哈希未变，默认策略仍为 heuristic。检查点记录累计 829 次更新，其中本次新增 400 次；诊断模型单独保存在 `logs/spatial-fit-v069/diagnostic.pt`。

388 项测试通过，包括抽样顺序不变性、互斥身份、重复样本拒绝及覆盖不足拒绝。完整结果、协议、样本身份与文件哈希见 `logs/spatial-fit-v069/results.json`、`protocol.json`、`selection.json`；运行时驱动副本也保存在该目录。

## 解释与下一步

结果排除了“现有架构完全无法拟合这 128 条标签”的解释，但不能区分依靠棋盘等细节记忆与真正学习协同规则，也不能排除全数据训练时的容量、优化或采样问题。均衡分组样本并不代表自然决策频率。本轮不评估闭环成绩，不晋级模型。

下一步适合预先固定一次全训练集延长训练对照，监测训练与验证分组误差是否同步下降；继续保留原权重和默认策略，避免根据这次 100% 小样本结果直接宣称训练问题已解决。
