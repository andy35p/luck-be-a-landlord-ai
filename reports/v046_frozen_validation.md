# V0.4.6：25% 候选冻结验证未通过

结论：不推广 25% 聚合候选。开发集的平均租金提升没有在本次新种子验证中复现，候选在主指标上落后于匹配预算的原始数据基线。保留两组模型及全部结果，不追加训练或比例搜索。

## 冻结方案

运行前核对种子登记和已有配置/清单，没有发现 40000–40999 被使用的记录。先保存 configs/bc_frozen_validation_v1.json，登记并消费该范围，再执行验证。两组各 1000 局，均来自 V0.4.5 的冻结检查点；模型、数据、环境源码哈希在运行期间复核一致。

比较对象是同为 534 次、每批 64 条有效决策训练的 0% 基线与 25% 候选，不是早期的三轮冒烟模型。主指标为平均通过租金，预定门槛为配对 95% bootstrap 区间下界大于零且双方零截断。固定 bootstrap 种子 46、5000 次重采样，无训练、无参数调整。

## 结果

| 指标 | 0% 匹配基线 | 25% 候选 |
|---|---:|---:|
| 局数 | 1000 | 1000 |
| 平均通过租金 | 5.393 | 5.176 |
| 第三期租金通过率 | 99.9% | 99.9% |
| 通关局数 | 90 | 90 |
| 截断局数 | 0 | 0 |

候选减基线的逐局平均差值为 **-0.217**，95% 区间 **[-0.367, -0.065]**。91 局改善、679 局相同、230 局下降。该区间不包含零，支持这两个固定检查点在当前种子分布下存在不利差异；不代表所有训练初始化或所有数据聚合方法均无效。

通关总数相同不能掩盖中途存活阶段的下降。部分最差种子从基线通关下降到仅通过 4 期租金，例如 40054、40081、40103、40112、40189。没有根据这些种子回头修改候选。

## 决策与边界

不将 25% 候选作为新默认或声称其泛化更好。保留 0% 匹配基线作为本实验的胜出对照；没有用本次结果判断它与早期 V0.3.7 模型谁更优，因为早期模型未加入本次冻结比较。

这次独立的是环境种子，两个模型仍只有一个初始化，且游戏规则为显式受限的近似后端。置信区间反映种子配对不确定性，不涵盖模拟器偏差、训练随机性或原版游戏。

40000–40999 现已消费。后续可把失败结果用于诊断，但再用这些种子只能称为开发复现，不能称为新的独立验证。下一步应整理当前基线和失败实验，优先完善规则覆盖/验证，而不是继续围绕同一小数据集试比例。
