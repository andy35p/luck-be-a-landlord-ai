# V0.2.9：煤炭选择评分单变量实验

## 假设和冻结方案

在 instance-coal-v1 / Floor 1 中，旧启发式对煤炭额外加 1.2，导致大量选入长期无收益的煤炭。本轮仅把煤炭评分偏移设为 -1.2，抵消该加分。其他符号评分、删除规则、环境、奖励和候选算法不变。没有训练模型。

实验前保存 `configs/v029_coal_experiment.json`：开发种子 0–299，验证种子 30000–30999，主指标平均通过租金，5000 次配对 bootstrap、95% 区间；门槛为区间下界大于零且双方无截断。没有搜索多个候选参数。验证前核对既有种子登记及日志，开发/验证配置和源码哈希一致。

## 结果

| 指标 | 开发基线 | 开发候选 | 验证基线 | 验证候选 |
|---|---:|---:|---:|---:|
| 局数 | 300 | 300 | 1000 | 1000 |
| 平均通过租金 | 2.110 | 4.980 | 2.052 | 4.946 |
| 平均 Spin 数 | 16.870 | 37.057 | 16.469 | 36.705 |
| 第三期租金通过率 | 19.67% | 99.67% | 17.7% | 98.8% |
| 通关局数 | 2 | 7 | 8 | 27 |
| 截断局数 | 0 | 0 | 0 | 0 |

开发配对提升 +2.870，95% 区间 [2.580, 3.177]；286 局改善、11 局相同、3 局下降。

验证配对提升 **+2.894**，95% 区间 **[2.736, 3.057]**；945 局改善、46 局相同、9 局下降。例如种子 30418 和 30849 从基线通过 13 期下降到 4 期，说明这不是每个种子都占优。通关率是次要描述指标，本轮未对其单独做显著性判定。

## 实现、兼容性与产物

HeuristicAgent 新增可选 `coal_score_adjustment`，默认仍为 0；候选为 -1.2。evaluate 支持同名关键字，只允许用于 heuristic。配置保持显式选择，不将受限环境结果静默推广到完整后端。

285 项测试通过，新增测试验证仅煤炭评分改变、默认等同旧评分、删除决策不变和非法参数拒绝。开发基线 300 局全部字段与 V0.2.7 保存的同种子结果一致，见 `v029_baseline_regression.json`。

实验脚本 `compare_coal.py` 保存两臂逐局 CSV、冻结配置、源码与数据联合哈希、汇总、配对区间和最差种子。验证运行要求提供通过门槛的开发结果，并核对配置和源码哈希未改变。

- 开发：`logs/v029-coal-development-20260922T030825773492Z`
- 验证：`logs/v029-coal-validation-20260922T030845640494Z`
- 两次源码/数据哈希：`4181b9cd2758b891f43656e7a819a798175e1414ef13f012761536b1093e91e8`

```powershell
python run_tests.py
python compare_coal.py
python compare_coal.py --phase validation --development-result logs/v029-coal-development-20260922T030825773492Z/comparison.json
```

上述验证种子现已消费，重跑只算复现，不是新的独立验证。种子登记已更新。Python 调用候选：`HeuristicAgent(catalog, coal_score_adjustment=-1.2)`。

## 结论与边界

该候选通过预定门槛，可作为当前煤炭受限环境的后续实验基线。结果支持取消当前不合适的煤炭加分，而不是证明煤炭普遍没有长期价值。相同种子配对的是两种完整策略路径；选牌差异也会改变后续抽样路径，不能解释为固定同一棋盘上的即时因果收益。区间不覆盖规则近似偏差，不能外推原版胜率。

下一步优先把已验证候选接入轨迹采集，核对改善后的动作与收益分布，形成版本明确的行为数据；继续暂缓深度模型训练，保留完整环境规则迁移的限制。
