# V091：安装与回滚演练

新增 manage_live_install.py，可在已安装 SlotWeave 的游戏目录中预检、安装或回滚本插件。默认只读，只有显式 --apply 才切换文件。

安装先校验本地包，再将现有插件完整复制到暂存目录，替换 DLL/manifest，生成文件哈希凭据；切换时将原目录保留为 previous。遇到可捕获的切换错误，会尝试恢复原目录。回滚核对当前插件与原备份哈希，归档新版本后恢复旧版。工具不删除备份，不操作用户存档。

已通过 5 项隔离测试：

- 已有插件安装与回滚，额外用户配置保持原样；只读预检不创建备份。
- 首次安装后回滚，新增插件归档保留。
- 游戏运行或安装后文件改变时拒绝操作。
- 模拟新目录切换失败后，原插件恢复。
- 备份损坏时拒绝回滚，当前安装不变。

对实际游戏目录仅执行了只读预检，确认读取到生产 DLL 指纹 818aca4b…，返回 applied=false；没有执行真实安装、回滚或启动游戏。假目录测试不能替代全新电脑和实际游戏安装验收。
