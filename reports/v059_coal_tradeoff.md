# V0.5.9：去掉煤炭加分的单变量开发实验

结论：不替换默认策略。候选明显改善早期生存，但通关率与平均奖励下降，不能把平均通过租金增加当作整体提升。

## 固定设计

沿用 instance-goldfish-v1 / revision 1，在完整开发种子 0–9999 上测试唯一候选：coal_score_adjustment=-1.2，抵消旧启发式煤炭固定 +1.2 分。其他符号评分、移除策略、物品选择、环境和奖励不变。默认值仍为 0。

配置在运行前写入 configs/v059_goldfish_coal.json，并连同驱动脚本保存到 logs/goldfish-coal-v059。复用 V0.5.7 的 10000 局默认启发式基线，运行前核对源码哈希、环境、规则修订、种子范围及默认策略配置；分析时进一步核对有效目录哈希。未搜索其他参数。

## 结果

| 指标 | 默认启发式 | 去掉加分 |
|---|---:|---:|
| 平均通过租金 | 6.4816 | 6.9394 |
| 通关数 | 1886 | 458 |
| 通关率 | 18.86% | 4.58% |
| 平均奖励 | 498.6561 | 435.1389 |
| 租金 3 生存率 | 90.64% | 99.87% |
| 租金 6 生存率 | 42.60% | 77.20% |
| 租金 8 生存率 | 26.91% | 24.43% |
| 租金 12 生存率 | 22.04% | 9.01% |
| 截断 | 0 | 0 |

平均通过租金差值 +0.4578，配对 bootstrap 95% 区间 [0.3792, 0.5378]。5678 局阶段更高、1677 局相同、2645 局更低。

通关率差值 -14.28 个百分点，配对 bootstrap 95% 区间 [-15.13, -13.42] 个百分点。1736 个种子由基线通关变为候选失败，308 个反向改善，150 个两者都通关。两项 bootstrap 均以整局种子为单位，2000 次，重采样种子 57。

移除固定成长偏好缓解了短期现金不足，却不能支撑同等后期通关表现；这是此项策略改动在开发集上的结果，不是单个煤炭选择的普遍因果结论。当前启发式还缺少收益期限与租金压力的联合判断。若继续研究，应先分析后期收益结构，再定义有状态的候选；不继续盲调常数。

## 验证与边界

365 项测试通过，新增金鱼有效符号池评分差分检查，确认只有煤炭评分变化。候选 10 局、1897 步轨迹精确重放，并与多进程结果前 10 局逐项一致。

未训练模型、未改变默认策略，也未消耗新的冻结验证种子。这里是同一受限近似环境的开发实验，不能推广为商业游戏胜率。默认保留是针对通关率和奖励退化的判断，不声称所有用户目标下候选都更差。
