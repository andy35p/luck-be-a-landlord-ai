# V109：周期评分独立对照——暂不替换教师

新增可选策略 heuristic_magpie_cycle，仅支持 instance-magpie-v1。对新喜鹊，用租金前剩余旋转数和固定库存下的出场概率计算周期奖励期望，再按预期出场次数归一化，与原教师的基础值评分比较。其他符号评分、删除及物品决策保持原教师行为。

假设库存固定、每转独立抽取；不考虑未来选牌、其他符号被挤占、存活条件及完整机会成本。因此这不是 Q 值或完整 EV。三次必出场时喜鹊评分为 -1，四次为 1.25，五次为 0.8。已有喜鹊的计数不用于新候选评分；原教师的删除行为也尚未针对周期优化。

预先固定方案 configs/v109_magpie_cycle_protocol.json：开发种子 0..999，若平均租金改善且无截断、胜率不退步，则运行留出种子 1000..1999；不做参数扫描。两个策略各跑两组，共 4,000 局，均无截断。

| 数据组 | 指标 | 原教师 | 周期实验 |
|---|---|---:|---:|
| 开发 1,000 种子 | 平均通过租金 | 6.541 | 6.757 |
| 开发 1,000 种子 | 胜率 | 17.6% | 21.5% |
| 留出 1,000 种子 | 平均通过租金 | 6.545 | 6.631 |
| 留出 1,000 种子 | 胜率 | 18.2% | 20.3% |

留出主指标的配对平均差为 +0.086，基于逐种子差值正态近似的 95% 区间约 [-0.075, 0.247]，不能充分确认改善。138 个种子更好、153 个更差、709 个相同。胜率差 +2.1 个百分点，近似区间 [0.15,4.05] 个百分点；这是次要指标，不用它替代主指标来宣布成功。结果仅适用于这个受限模拟器。

在候选策略实际到达的 49,228 次符号选择状态中，与原教师有 811 次动作分歧。该统计比较同一候选轨迹状态上的两个策略，不是把已分叉的整条对局逐步强行对齐。原始逐局结果、源码指纹和区间计算见 logs/v109-holdout；摘要见 v109_development.json、v109_holdout.json。

新增 4 项测试通过，含短期延迟、穷举 2^7 种出场序列对照、域限制、合法动作与确定性。既有并行评估 3 项测试通过。未重复全量测试，未修改默认教师、模型、BC 数据、实时白名单或用户游戏文件。

决策：暂不推广；不扩大样本来追逐显著性，也不依据留出结果即时调参。下一步可诊断已保存的受损种子，区分临近租金收入延迟、后续移除喜鹊或其他选择分叉；任何新策略需独立新协议和未使用种子。

复现单组：

```powershell
python evaluate.py --agent heuristic_magpie_cycle --games 1000 --seed-start 0 --config configs/instance_magpie_v1.json --output logs/cycle-reproduction
python tools/compare_magpie_cycle.py --seed-start 1000 --games 1000 --output logs/cycle-holdout-reproduction
```

比较工具要求新输出目录，保留原证据。它不会训练模型或更改实时助手配置。最新助手包仍为 V107。
